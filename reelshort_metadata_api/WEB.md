# NovelPlay Web (sem APK)

Acesse diretamente **https://novelplay-api.onrender.com/** no Chrome Android.

A versão web usa as mesmas rotas de catálogo do aplicativo Flutter e oferece:
recomendados, novidades, dublados, busca, favoritos locais, detalhes,
lista informativa dos episódios e botão para abrir a página **oficial** do
ReelShort. Não exige instalação de APK.

Para adicionar um atalho: Chrome → menu ⋮ → **Adicionar à tela inicial**.

A fonte comunitária pode mudar e ficar indisponível. O serviço não extrai
links de vídeo de episódios protegidos; episódios premium continuam sujeitos
aos termos e às restrições do ReelShort.

Os arquivos estáticos são servidos diretamente pelo servidor Node do Render
a partir da pasta `reelshort_metadata_api/public`. Sem dependências externas
e sem outro serviço para pagar.
